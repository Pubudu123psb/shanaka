# shanaka

Mobile app built with [Expo](https://expo.dev) and [Expo Router](https://docs.expo.dev/router/introduction/).

## Get started

```bash
npm install
npx expo start
```

- Press `w` for web, or scan the QR code with Expo Go on a device.
- Screens live in `src/app/` (see `AGENTS.md` for project conventions).

## Scripts

| Command | Description |
| --- | --- |
| `npx expo start` | Dev server |
| `npx tsc --noEmit` | Typecheck |
| `npx expo-doctor` | Check SDK compatibility |
